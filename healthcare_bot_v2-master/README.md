# Med Assist AI

An AI-powered health assistant application that helps users check symptoms, find nearby hospitals, and get health information. Built with HTML, CSS, and JavaScript.

## Features

- **Symptom Checker**: Select symptoms to get possible health conditions
- **AI Chatbot**: Interactive health assistant chat
- **Hospital Finder**: Locate hospitals across India with map integration
- **Emergency Assistance**: Quick access to emergency services
- **Multilingual Support**: Available in English, Hindi, and Telugu
- **User Profiles**: Save your information and preferences
- **Health Tips**: Daily health advice and reminders
- **Consultation History**: Track your health consultations
- **Dark Mode**: Toggle between light and dark themes

## Setup Instructions

1. **Clone or download the repository**
2. **Open `index.html` in any modern web browser**
3. **No installation required** - the app runs entirely in the browser

## Usage

1. **Symptom Checker**:
   - Go to the Symptoms section
   - Select your symptoms from the list
   - Add duration and severity
   - Click "Analyze Symptoms" to get possible conditions

2. **AI Chatbot**:
   - Go to the Chat section
   - Type your health questions or symptoms
   - Get instant responses from the AI assistant

3. **Hospital Finder**:
   - Go to the Hospitals section
   - Browse hospitals by city or type
   - Use the map view to see hospital locations
   - Click on a hospital for details and directions

4. **Emergency Assistance**:
   - Click the emergency button in the chat
   - Get immediate access to emergency numbers and nearby hospitals
